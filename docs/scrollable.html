Scrollable Tables

Overview

Scrollable tables allow you to handle large datasets and wide tables efficiently by providing horizontal and vertical scrolling capabilities with sticky column support.

Key Features

  • Dynamic height with maximum height constraints
  • Horizontal scrolling for wide tables
  • Sticky columns (left and right)
  • Custom scrollbar styling
  • Responsive design
  • Shadow effects for sticky columns

Basic Configuration

Enable Scrollable Table

<template>
  <DataTable
    :data="products"
    :columns="columns"
    :config="config"
  />
</template>

<script setup>
import { ref } from 'vue'
import DataTable from '@/components/DataTable/DataTable.vue'

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      maxHeight: '500px',  // Maximum height before vertical scroll
      width: '100%',       // Full width, horizontal scroll when needed
      stickyColumns: {
        left: ['id'],      // Stick ID column to the left
        right: []          // No right sticky columns
      }
    }
  }
})
</script>

Vertical Scrolling

Control the table height and enable vertical scrolling when content exceeds the specified height.

Dynamic Height

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      maxHeight: '500px'  // Table grows naturally up to 500px, then scrolls
    }
  }
})

// Alternative: Fixed height
const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      height: '400px'     // Fixed height, always shows scrollbar if needed
    }
  }
})

Height Options

maxHeight (Recommended)

Table grows naturally with content up to the maximum height

  • • No empty space with few rows
  • • Scrollbar appears when needed
  • • Better user experience

height (Fixed)

Table always has the specified height

  • • Consistent table height
  • • May show empty space
  • • Always shows scrollbar area

Horizontal Scrolling

Handle wide tables with many columns by enabling horizontal scrolling. 

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      width: '100%',      // Full container width
      maxHeight: '500px'
    }
  }
})

// Column width configuration
const columns = ref([
  {
    key: 'id',
    title: 'ID',
    width: '80px',      // Fixed width
    minWidth: '60px'    // Minimum width
  },
  {
    key: 'name',
    title: 'Product Name',
    width: '200px',
    minWidth: '150px'
  },
  {
    key: 'description',
    title: 'Description',
    width: '300px',     // Wide column
    minWidth: '200px'
  },
  {
    key: 'category',
    title: 'Category',
    width: '120px'
  },
  {
    key: 'price',
    title: 'Price',
    width: '100px',
    align: 'right'
  }
])

Sticky Columns

Keep important columns visible while scrolling horizontally by making them sticky.

Left Sticky Columns

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      maxHeight: '500px',
      stickyColumns: {
        left: ['id', 'name'],  // ID and Name columns stick to the left
        right: []
      }
    }
  }
})

Right Sticky Columns

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      maxHeight: '500px',
      stickyColumns: {
        left: ['id'],
        right: ['actions', 'status']  // Actions and Status stick to the right
      }
    }
  }
})

Both Left and Right Sticky

const config = ref({
  ui: {
    scrollable: {
      enabled: true,
      maxHeight: '500px',
      stickyColumns: {
        left: ['id', 'name'],        // Important info on the left
        right: ['actions', 'status'] // Actions on the right
      }
    }
  }
})

Best Practices

Column Width Management

  • Set explicit widths for important columns
  • Use minWidth to prevent columns from becoming too narrow
  • Keep sticky columns relatively narrow
  • Consider responsive breakpoints for column visibility

Sticky Column Selection

  • Stick essential identification columns (ID, Name) to the left
  • Stick action columns to the right
  • Limit the number of sticky columns (2-3 max)
  • Ensure sticky columns have fixed widths

Performance Considerations

  • Use maxHeight instead of fixed height when possible
  • Implement virtual scrolling for very large datasets
  • Consider pagination to limit rows per page
  • Optimize column rendering for better scroll performance

Browser Support

Scrollable tables work in all modern browsers with the following considerations:

Full Support

  • • Chrome 88+
  • • Firefox 85+
  • • Safari 14+
  • • Edge 88+

Limited Support

  • • IE 11: Basic scrolling only
  • • Older browsers: No custom scrollbars
  • • Mobile: Touch scrolling supported
