Installation

Prerequisites

Before installing the Vue DataTable component, make sure you have:

  • Vue.js 3.0 or higher
  • Node.js 16.0 or higher
  • Tailwind CSS (for styling)
  • Heroicons (for icons)

Method 1: Copy Components (Recommended)

Since this is a custom component built for your project, the recommended approach is to copy the component files directly into your Vue.js project.

Step 1: Copy Component Files

Copy the following files to your project:

# Create the DataTable directory
mkdir -p src/components/DataTable

# Copy all component files
src/components/DataTable/
├── DataTable.vue                 # Main DataTable component
├── DataTableToolbar.vue          # Toolbar with search, export, etc.
├── DataTablePagination.vue       # Pagination component
├── DataTableCell.vue             # Individual cell renderer
├── SearchableSelect.vue          # Searchable dropdown component
├── AdditionalFilters.vue         # Additional filters component
├── composables/
│   └── useDataTable.js          # DataTable composable
└── utils/
    └── exportUtils.js           # Export utilities

Step 2: Install Dependencies

# Install required dependencies
npm install @heroicons/vue

Step 3: Configure Tailwind CSS

Make sure Tailwind CSS is properly configured in your project:

// tailwind.config.js
module.exports = {
  content: [
    "./index.html",
    "./src/**/*.{vue,js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
/* src/style.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

Verify Installation

Create a simple test to verify the installation:

<!-- src/components/TestDataTable.vue -->
<template>
  <div class="p-8">
    <h1 class="text-2xl font-bold mb-4">DataTable Test</h1>
    <DataTable
      :data="testData"
      :columns="testColumns"
      :config="testConfig"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import DataTable from './DataTable/DataTable.vue'

const testData = ref([
  { id: 1, name: 'Product 1', price: 100 },
  { id: 2, name: 'Product 2', price: 200 },
  { id: 3, name: 'Product 3', price: 300 }
])

const testColumns = ref([
  { key: 'id', title: 'ID', sortable: true },
  { key: 'name', title: 'Name', sortable: true },
  { key: 'price', title: 'Price', type: 'currency', sortable: true }
])

const testConfig = ref({
  pagination: { enabled: true, pageSize: 10 },
  filtering: { enabled: true },
  ui: { striped: true, hover: true }
})
</script>

Troubleshooting

Icons not showing

Make sure Heroicons is installed:

npm install @heroicons/vue

Styles not applied

Ensure Tailwind CSS is properly configured and imported in your main.js:

// main.js
import './style.css' // Make sure this includes Tailwind

Component not found

Check the import path in your component:

// Adjust the path based on your project structure
import DataTable from '@/components/DataTable/DataTable.vue'
