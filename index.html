Vue DataTable Component

A powerful, feature-rich Vue.js DataTable component with server-side support, advanced filtering, sorting, pagination, and much more. Built with Vue 3 and Tailwind CSS.

Server-Side Support

Full server-side processing with Laravel API integration for large datasets.

Advanced Filtering

Column filters, searchable selects, and additional custom filters.

Smart Sorting

Server-side sorting with visual indicators and multi-column support.

Scrollable Tables

Horizontal and vertical scrolling with sticky columns support.

Export Features

Export to CSV, Excel, JSON with customizable options.

Highly Customizable

Flexible configuration with custom cell renderers and themes.

Quick Start

# Install the component
npm install vue-datatable-component

# Import in your Vue app
import { DataTable } from 'vue-datatable-component'

Basic Example

<template>
  <DataTable
    :data="products"
    :columns="columns"
    :config="config"
    server-side
    @filter="handleFilter"
    @sort="handleSort"
    @paginate="handlePaginate"
  />
</template>

<script setup>
import { ref } from 'vue'
import DataTable from '@/components/DataTable/DataTable.vue'

const products = ref([])
const columns = ref([
  { key: 'id', title: 'ID', sortable: true },
  { key: 'name', title: 'Product Name', sortable: true, filterable: true },
  { key: 'price', title: 'Price', type: 'currency', sortable: true }
])

const config = ref({
  pagination: { enabled: true, pageSize: 10 },
  filtering: { enabled: true, additionalFilters: { enabled: true } },
  ui: { scrollable: { enabled: true, maxHeight: '500px' } }
})
</script>
