Basic Usage

Quick Start

Get started with the DataTable component in just a few steps. This guide covers the basic setup and common use cases. 

<template>
  <div class="p-6">
    <h1 class="text-2xl font-bold mb-4">My Products</h1>
    <DataTable
      :data="products"
      :columns="columns"
      :config="config"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import DataTable from '@/components/DataTable/DataTable.vue'

// Sample data
const products = ref([
  { id: 1, name: 'Laptop', category: 'Electronics', price: 999.99, status: 'active' },
  { id: 2, name: 'Book', category: 'Education', price: 29.99, status: 'active' },
  { id: 3, name: 'Headphones', category: 'Electronics', price: 199.99, status: 'inactive' }
])

// Column definitions
const columns = ref([
  { key: 'id', title: 'ID', sortable: true },
  { key: 'name', title: 'Product Name', sortable: true },
  { key: 'category', title: 'Category', sortable: true },
  { key: 'price', title: 'Price', type: 'currency', sortable: true },
  { key: 'status', title: 'Status', type: 'badge', sortable: true }
])

// Basic configuration
const config = ref({
  pagination: { enabled: true, pageSize: 10 },
  filtering: { enabled: true },
  ui: { striped: true, hover: true }
})
</script>

Data Structure

The DataTable expects an array of objects where each object represents a row.

Basic Data Format

const data = ref([
  {
    id: 1,
    name: 'Product 1',
    category: 'Electronics',
    price: 99.99,
    status: 'active',
    created_at: '2024-01-01T00:00:00Z'
  },
  {
    id: 2,
    name: 'Product 2',
    category: 'Books',
    price: 19.99,
    status: 'inactive',
    created_at: '2024-01-02T00:00:00Z'
  }
])

Required Fields

  • Unique Identifier: Each row should have a unique identifier (usually 'id' or '_id')
  • Consistent Structure: All objects should have the same property structure
  • Data Types: Use appropriate data types (strings, numbers, dates, booleans)

Column Configuration

Columns define how your data is displayed and what features are available for each column.

Basic Column Properties

const columns = ref([
  {
    key: 'id',              // Data property key
    title: 'ID',            // Column header text
    sortable: true,         // Enable sorting
    filterable: false,      // Disable filtering
    width: '80px',          // Fixed width
    align: 'center'         // Text alignment
  },
  {
    key: 'name',
    title: 'Product Name',
    sortable: true,
    filterable: true,
    filterType: 'text',     // Filter input type
    placeholder: 'Search products...'
  },
  {
    key: 'price',
    title: 'Price',
    type: 'currency',       // Display type
    sortable: true,
    align: 'right'
  }
])

Column Types

Plain text display

Formatted currency display

Configuration Options

The config object controls the behavior and appearance of the DataTable.

Complete Configuration

const config = ref({
  // Pagination settings
  pagination: {
    enabled: true,
    pageSize: 10,
    pageSizes: [5, 10, 25, 50],
    showInfo: true,
    showSizeChanger: true
  },
  
  // Filtering settings
  filtering: {
    enabled: true,
    global: true,           // Global search
    column: true,           // Column filters
    debounce: 300,          // Debounce delay
    additionalFilters: {
      enabled: true         // Additional filters panel
    }
  },
  
  // Sorting settings
  sorting: {
    enabled: true,
    multiple: false         // Single column sorting
  },
  
  // Selection settings
  selection: {
    enabled: true,
    multiple: true,
    showSelectAll: true
  },
  
  // Export settings
  export: {
    enabled: true,
    formats: ['csv', 'excel', 'json'],
    filename: 'data-export'
  },
  
  // UI settings
  ui: {
    striped: true,          // Striped rows
    bordered: true,         // Table borders
    hover: true,            // Hover effects
    compact: false,         // Compact spacing
    stickyHeader: true,     // Sticky header
    loading: false,         // Loading state
    noDataText: 'No data found',
    loadingText: 'Loading...',
    scrollable: {
      enabled: true,
      maxHeight: '500px'
    }
  }
})

Event Handling

The DataTable emits various events that you can listen to for custom functionality. 

<template>
  <DataTable
    :data="products"
    :columns="columns"
    :config="config"
    @row-click="handleRowClick"
    @cell-update="handleCellUpdate"
    @sort="handleSort"
    @filter="handleFilter"
    @page-change="handlePageChange"
    @export="handleExport"
  />
</template>

<script setup>
// Event handlers
function handleRowClick(row) {
  console.log('Row clicked:', row)
  // Navigate to detail page, open modal, etc.
}

function handleCellUpdate({ row, column, value }) {
  console.log('Cell updated:', { row, column, value })
  // Update data, call API, etc.
}

function handleSort({ column, direction }) {
  console.log('Sort changed:', { column, direction })
  // For client-side: handled automatically
  // For server-side: fetch new data
}

function handleFilter({ key, value, type }) {
  console.log('Filter applied:', { key, value, type })
  // For client-side: handled automatically
  // For server-side: fetch filtered data
}

function handlePageChange(page) {
  console.log('Page changed:', page)
  // For client-side: handled automatically
  // For server-side: fetch page data
}

function handleExport({ format, filename, data }) {
  console.log('Export requested:', { format, filename })
  // Custom export logic if needed
}
</script>

Common Patterns

Loading State

<script setup>
const loading = ref(false)
const products = ref([])

const config = ref({
  ui: {
    loading: loading.value,
    loadingText: 'Loading products...'
  }
})

async function fetchProducts() {
  loading.value = true
  try {
    const response = await fetch('/api/products')
    products.value = await response.json()
  } finally {
    loading.value = false
  }
}

onMounted(fetchProducts)
</script>

Empty State

const config = ref({
  ui: {
    noDataText: 'No products found. Try adjusting your filters.',
    // Custom empty state component
    emptyStateComponent: 'CustomEmptyState'
  }
})

Badge Configuration

const columns = ref([
  {

      'pending': 'bg-yellow-100 text-yellow-800',
      'error': 'bg-red-100 text-red-800'
    }
  }
])

Best Practices

Data Management

  • Always provide unique identifiers for each row
  • Use consistent data types across rows
  • Handle null/undefined values gracefully
  • Consider using reactive data sources

Performance

  • Use pagination for large datasets (>100 rows)
  • Implement server-side processing for very large datasets
  • Debounce filter inputs to reduce API calls
  • Consider virtual scrolling for extremely large tables

User Experience

  • Provide clear column headers and labels
  • Use appropriate column types for better formatting
  • Include loading states for async operations
  • Implement proper error handling and messages
