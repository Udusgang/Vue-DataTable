Additional Filters

Overview

Additional Filters provide a way to filter data by fields that are not visible as table columns. These filters appear as a collapsible panel above the table, allowing users to filter by fields like created_at, updated_at, created_by, and updated_by.

Key Features

  • Toggle button to show/hide filter panel
  • Filter count badge on the button
  • Date filters for created_at and updated_at
  • Text filters for created_by and updated_by
  • Debounced text input for better performance
  • Clear all filters functionality
  • Server-side integration

Basic Setup

Enable Additional Filters

<template>
  <DataTable
    :data="products"
    :columns="columns"
    :config="config"
    server-side
    @filter="handleFilter"
  />
</template>

<script setup>
import { ref } from 'vue'
import DataTable from '@/components/DataTable/DataTable.vue'

const config = ref({
  filtering: {
    enabled: true,
    global: true,
    column: true,
    additionalFilters: {
      enabled: true  // Enable additional filters
    }
  }
})

// Handle filter events
async function handleFilter({ key, value, type }) {
  console.log('Filter applied:', { key, value, type })
  
  // Update your filters state and fetch data
  if (value === '' || value === null || value === undefined) {
    delete currentFilters.value[key]
  } else {
    currentFilters.value[key] = { value, type: type || 'contains' }
  }
  
  await fetchData()
}
</script>

Available Filters

Created Date

Filter by creation date

  • Field: created_at
  • Type: Date picker
  • API Parameter: filter[created_at]

Updated Date

Filter by last update date

  • Field: updated_at
  • Type: Date picker
  • API Parameter: filter[updated_at]

Created By

Filter by creator name

  • Field: created_by
  • Type: Text input (debounced)
  • API Parameter: filter[created_by]

Updated By

Filter by updater name

  • Field: updated_by
  • Type: Text input (debounced)
  • API Parameter: filter[updated_by]

Server-Side Integration

Laravel Controller

<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Product;
use Illuminate\Http\Request;

class ProductController extends Controller
{
    public function index(Request $request)
    {
        $query = Product::with(['creator', 'updater']);
        
        // Apply additional filters
        $this->applyAdditionalFilters($query, $request);
        
        // Apply other filters, sorting, etc.
        $this->applyFilters($query, $request);
        $this->applySorting($query, $request);
        
        return response()->json($query->paginate($request->get('per_page', 10)));
    }
    
    private function applyAdditionalFilters($query, Request $request)
    {
        $filters = $request->get('filter', []);
        
        // Created Date filter
        if (!empty($filters['created_at'])) {
            $query->whereDate('created_at', $filters['created_at']);
        }
        
        // Updated Date filter
        if (!empty($filters['updated_at'])) {
            $query->whereDate('updated_at', $filters['updated_at']);
        }
        
        // Created By filter
        if (!empty($filters['created_by'])) {
            $query->whereHas('creator', function ($q) use ($filters) {
                $q->where('name', 'LIKE', '%' . $filters['created_by'] . '%');
            });
        }
        
        // Updated By filter
        if (!empty($filters['updated_by'])) {
            $query->whereHas('updater', function ($q) use ($filters) {
                $q->where('name', 'LIKE', '%' . $filters['updated_by'] . '%');
            });
        }
    }
}

Model Relationships

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    protected $fillable = [
        'name', 'description', 'category', 'price', 'stock', 'status',
        'created_by', 'updated_by'
    ];
    
    // Relationship to get creator information
    public function creator()
    {
        return $this->belongsTo(User::class, 'created_by');
    }
    
    // Relationship to get updater information
    public function updater()
    {
        return $this->belongsTo(User::class, 'updated_by');
    }
}

API Parameters

When additional filters are applied, the following parameters are sent to your API: 

# Example API requests with additional filters

# Filter by created date
GET /api/products?filter[created_at]=2024-01-01&filter_type[created_at]=contains

# Filter by created by
GET /api/products?filter[created_by]=john&filter_type[created_by]=contains

# Multiple additional filters
GET /api/products?filter[created_at]=2024-01-01&filter_type[created_at]=contains&filter[created_by]=john&filter_type[created_by]=contains

# Combined with other filters
GET /api/products?page=1&per_page=10&sort=name&direction=asc&filter[name]=product&filter_type[name]=contains&filter[created_at]=2024-01-01&filter_type[created_at]=contains

Best Practices

Performance

  • Use database indexes on filtered columns (created_at, updated_at, created_by, updated_by)
  • Consider using eager loading for user relationships
  • Implement proper debouncing for text inputs (already included)

User Experience

  • Show filter count badge to indicate active filters
  • Provide clear labels and placeholders
  • Include a "Clear Filters" button for easy reset
  • Use appropriate input types (date, text, select)

Security

  • Validate and sanitize all filter inputs on the server
  • Use parameterized queries to prevent SQL injection
  • Implement proper authorization for filtered data
  • Limit the fields that can be filtered

Usage Examples

Filter by Creation Date

1. Click "Additional Filters" button
2. Select a date in the "Created Date" field
3. Table updates immediately with records created on that date

Filter by Creator

1. Click "Additional Filters" button
2. Type a name in the "Created By" field
3. After 300ms debounce, table updates with records created by that user

Multiple Filters

1. Apply multiple additional filters simultaneously
2. Each filter adds to the query (AND logic)
3. Filter count badge shows total active filters
4. Use "Clear Filters" to reset all at once
